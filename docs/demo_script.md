# Demo Video Script (draft)

Target length: 2-4 min.

1. **Hook (10-15s)** — one AI-generated image and one real image side by
   side; can the viewer tell which is which? Then reveal.
2. **Problem framing (20-30s)** — why robustness matters (compression,
   reposting, cropping breaks naive detectors).
3. **Approach (30-45s)** — backbone + robustness-aware training, screen
   recording of `infer.py` running on a folder of images.
4. **Robustness results (30-45s)** — show the clean-vs-transformed table
   / chart from Person C.
5. **Error analysis (20-30s)** — one false positive, one false negative,
   Grad-CAM overlay if it adds clarity.
6. **Wrap-up (10-15s)** — limitations + what you'd do with more time.

Notes:
- No third-party trademarks/copyrighted content on screen.
- Record screen at 1080p, keep terminal font large and readable.
- Upload to YouTube, set to Public, link in Devpost description.
